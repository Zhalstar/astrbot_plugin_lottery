## 🤝 介绍

抽奖插件，可自定义抽奖活动的权重、奖品和奖品数量

## 📦 安装

在astrbot的插件市场搜索astrbot_plugin_lottery，点击安装即可

## ⌨️ 使用说明

### 命令表

| 命令              | 说明              |
| --------------- | --------------- |
| `开启抽奖`          | 在本群启动一轮新抽奖活动    |
| `抽奖`            | 参与当前抽奖，即时得知是否中奖 |
| `抽奖状态`          | 显示活动进行状态、剩余奖品数量 |
| `中奖名单`          | 列出本群已中奖用户及对应奖项  |
| `关闭抽奖`          | 立即结束本轮抽奖并锁定结果   |
| `重置抽奖`          | 重置本群的抽奖活动   |

### 默认奖项

在插件配置页可以按条目添加任意档位的奖项，并设置奖品名称、中奖权重和数量。实际概率为该项权重除以当前候选项权重之和，未中奖也有独立权重。开启抽奖时会复制当前配置；奖项列表为空时，插件会自动写入四档默认奖项。
